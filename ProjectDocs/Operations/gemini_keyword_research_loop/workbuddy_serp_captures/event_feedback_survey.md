## Intent interpretation

**Primary intent**: Template / Example / How-to
- Searchers want ready-made post-event or conference feedback forms, question lists, and templates they can copy or use immediately.
- Google AI Overview appears on `post event survey form`, confirming the query is educational/template-oriented.
- Image packs dominate the conference-feedback query, reinforcing that visual templates are a strong intent signal.

**Secondary intent**: Platform comparison
- Heavy presence of SurveyMonkey, Typeform, Microsoft Forms, Google Forms, Jotform, Qualtrics, and smaller template sites.
- A smaller subset of users is looking for a dedicated feedback tool (Qualtrics ads, QuestionPro, SurveySparrow).

## Product truth fit for GenForms.ai

**Strong fit**:
- GenForms can AI-generate a post-event / conference feedback form in seconds.
- Shareable public link + QR code fits the "hand out at events / print on signs" use case.
- Native webhooks can push responses to Slack / WeCom / DingTalk / Feishu for real-time event-team alerts.
- Pro plan ($19/mo) is cheaper than SurveyMonkey / Typeform paid tiers.

**Current limitations**:
- No pre-built event-feedback template gallery in the product yet.
- No direct Microsoft Forms / Google Forms import.
- No advanced event analytics (session-level, speaker-level ratings) beyond basic form results.

## Build recommendation
**Build (Candidate)**

**Reason**: Real SERP evidence shows the query cluster is heavily template/example-driven. There is no AI-native form competitor visible in the captured results. GenForms can differentiate with an AI-generated event-feedback template page that gives users a ready-to-use form + QR code + webhook notification flow in one click.
