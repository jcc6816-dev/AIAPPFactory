## Intent interpretation
**Primary intent**: Find a way to create a customer feedback form that can be accessed via QR code (for physical locations, events, receipts, packaging, etc.).

**Secondary intent**: Learn how to generate a QR code for an existing survey, compare tools that bundle QR-code generation, or find a free QR-code generator.

**Commercial intent**: Moderate. Some users want a dedicated feedback platform; others just want a free QR code generator to pair with any form link.

**User profile**: Small business owners, event organizers, retail/restaurant operators, customer-experience teams, and marketers who want to collect in-person feedback.

**Evidence count**: 3 successful captures covering 2 unique query variations (2 captures of `feedback form with QR code`, 1 capture of `QR code customer feedback form`).

## Product truth fit for GenForms.ai

**GenForms MVP capabilities that match**:
- Can create branded, shareable public forms with a public link.
- AI-native form generation can quickly produce customer feedback / NPS / CSAT forms.
- Webhooks can push QR-code scan responses to Slack, email, CRM, or analytics in real time.
- FormSkills (email notification, AI insights, data cleaning) can automate feedback workflows.
- Lower price point than SurveyMonkey/Typeform/AskNicely for teams that need advanced features.

**GenForms MVP limitations that are gaps**:
- **No confirmed native QR-code generation feature** in the current product. Users would need to paste the public form URL into a third-party QR code generator (Canva, Bitly, QR Code Generator).
- No direct comparison to SurveyMonkey/Typeform QR-code features in GenForms marketing.
- Brand authority is far below SurveyMonkey, Typeform, and Microsoft/Google documentation.

**Overall fit**: Moderate-Strong
**Matching count**: 3 (AI form generation, shareable public link, webhook automation)
**Gap count**: 1 (native QR-code generation may need to be added or positioned as a feature)
