# GenForms 首次成功闭环导航层级修正记录

日期：2026-07-04

## 总体结论

已解决首次成功流程与长期功能导航相互竞争的问题。用户现在只会看到一套可点击的长期导航；首次成功流程以轻量状态栏表达当前进度和下一步，不再伪装成第二套导航。

## 主要变化

1. 新建表单页不再显示不可用的长期功能菜单。
2. 已创建表单保留 `Design / Data / Analytics / Publish`。
3. 五步激活流程合并进场景状态栏。
4. 移动端顶部由三层信息减少为两层。
5. 英文未生成状态不再显示中文字段。
6. 第一条结果首帧不再闪现普通数据表。
7. 发布、测试和结果页不再提供容易离开当前表单的“更换场景”入口。
