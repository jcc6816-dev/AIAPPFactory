## 1. 执行摘要 (Executive Summary)

根据对 6 个核心关键词在 Google US SERP 的深度检索和对代表竞品页面承接路径的拆解，我们对 **Community Application Form** 主题得出如下核心结论：
*   **严重的意图污染与物理功能错配**：
    1.  **意图污染**：在 Google US 搜索中，泛 `community application` 词群受到强烈的**非互联网社群**污染。首屏充斥着地方政府的“社区开发拨款申请表（Community Development Grant PDF）”、房地产开发商的“封闭小区开发规划表（Gated Community Application PDF）”以及大学招生（Admissions）表格。只有具体到 `creator community application` 时，才是品牌的网红合作申请（Influencer program）。
    2.  **物理红线冲突**：对于私域或会员制社群，运营者的核心痛点是 **“成员审批流 (Approval Pipeline)”**（后台点击“通过”后自动发放单次有效的群链接）以及 **“Discord/Slack 自动入群邀请 (Platform Invite Sync)”**，甚至包含**“周期性会员费扣款 (Recurring Membership Fee)”**。GenForms 当前 MVP 版本**不支持任何后台审批流**，**不支持 Discord/Slack 原生 API 自动生成邀请码**，**不支持会员订阅按月收费**。
*   **最终决策**：**Template-only coverage (仅做模板库覆盖，拒绝进入 Architect 扩张，在 existing Template 中增加警示免责声明)**。因为该场景的真实业务链条极度依赖“表单提交 -> 人工/自动审核 -> 平台授权”，如果在页面上强推该解决方案，极易吸引来需要全功能社区管理系统的用户，从而因为功能缺失导致转化崩溃。

## 4. 深度意图与核心任务解构 (Deep Intent & User Tasks)

1.  **Search Intent (搜索意图)**：
    *   用户在寻找能用于私域会员群（Discord/Slack/微信群/知识星球）的入群筛选及成员背景登记模板。
    *   **核心期望**：通过几个深度开放问题（加入动机、可贡献资源、自我介绍）来筛选符合社群定位的高质量成员。
2.  **User's Immediate Task (用户的即时任务)**：
    *   社群主（Community Manager）要在官推或落地页放置申请表。收集数据后，通过审核的成员将被发放邀请码，或者通过邮件联系。
3.  **Expected Capabilities (期望的产品能力)**：
    *   **成员审核流 (Admin Approval Flow)**：在表单后台对申请者进行“Approve/Reject”操作，决定是否发放绿卡。
    *   **入群凭证自动化 (Community Sync)**：与 Discord/Slack API 原生对接，审核通过后自动生成一次性邀请链接发给用户。
    *   **会员费周期收缴 (Recurring billing)**：高客单价社群需要绑定 Stripe Subscription 周期付款。
4.  **GenForms Support Status (GenForms 支持状态)**：
    *   **不支持（红线排除）**：不支持任何后台人工审批状态机（通过/驳回按钮），不支持 Discord/Slack 原生 API 互通自动发链接，不支持 Stripe 周期订阅自动扣款。
    *   **支持**：学员基础字段收集，Webhook 实时通知团队有新申请，单题流高转化筛选。

## 5. 最终决策与红线划分 (Final Decision & Redlines)

### 最终决策：**Template-only coverage (仅做模板库覆盖，拒绝进入 Architect 阶段，不为其建立 Use Case 场景页，仅做 long-tail 模板展示，在 existing template 中增加警示免责声明)**

*   **核心依据**：
    1.  **产品功能严重缺失**：社群申请的核心是**“闭环审核与下发群凭证”**。在不支持控制台审批状态流、不支持 Discord/Slack 单次邀请码同步的前提下，GenForms 仅仅能扮演“单纯的数据收集框”，这会导致希望自动化运营的社群主面临体验落差。
    2.  **搜索意图极度杂乱**：如 SERP 所示，`community application` 大量被政府拨款 PDF、住宅封闭小区规划 PDF 污染。用户搜这个词有很多并非是想找互联网表单工具。
    3.  **避免过度承诺**：现有在 `solution-landing-pages.ts` 中的 [community-application-form-template](file:///Users/mike/Documents/AIFactory/Code/services/solution-landing-pages.ts#L1009) 页面仅作为静态长尾模板承接。我们**绝不应该**为其开辟独立的 main `/use-cases/` 场景。

### 现有资产调整行动项 (Action Items)：
*   **优化 `/solutions/community-application-form-template` 的 FAQ 与描述**：
    *   *修改 recommendedFields*：
      将 `"Background"` 修改为 `"Background (Linkedin or text summary)"`。
    *   *增加 FAQ 免责提示*：
      > **Q: Can GenForms automatically approve members and generate Discord or Slack invites? (它能自动审核并生成 Discord 或 Slack 邀请链接吗？)**  
      > **A**: No. GenForms acts as a screening intake tool to collect background and motivation. The review process is manual. Once you qualify an applicant, you must send the platform invite link separately via your own team email or chat tools.
