Product surface

Make the invisible automation layer visible.

A small team does not want to debug Zapier-like failures by reading server logs. The product should translate delivery results into actions.

  • Green means the next system accepted the submission.
  • Yellow means GenForms is retrying automatically.
  • Red means the user gets a specific fix path.
  • Every row keeps the submission, endpoint, response, and retry audit trail.
